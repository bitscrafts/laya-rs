## 7. Rules that were broken today, so they are not broken again

- **A check's input must come from the live path.** Broken five times in one day, by me: a control that
  tested the parser instead of the dispatcher (three attempts to fix), a gate that summed a truncated
  cargo stream and reported 331 where the truth was 538, a hook probe that nested `session_id` wrongly
  and reported "not firing", and a documented CLI subcommand invented from memory. Every one of them
  reported success while checking nothing. **Suspect the check first.**
- **`hermes hooks doctor`'s "script modified since approval" is a warning, not a disablement.** The
  allowlist matches on event and command only. Chasing it costs time.
- **Hooks load at process start.** A session in flight when a hook is registered is not gated by it.
- **Commits must name no AI tool** — message, author *and* email. The `commit-msg` hook scans the body
  and refused two commits today for the word "Hermes". Write the commit to `.git/COMMIT_*.txt` and use
  `git commit -F`.
- **The `terminal` tool blocks long inline one-liners and heredocs.** Write a script to
  `/projects/_tmp/` and run that.
